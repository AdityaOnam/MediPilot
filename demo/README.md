# Demonstration Artifacts (`demo/`)

> **All data in this repository is synthetic.**

This directory contains the visual evidence of the MediPilot prototype in action. These assets were generated strictly using the synthetic `corpus_20.json` seed and contain zero patient information.

## Contents
1. **`banner.jpg`**: The primary MediPilot banner used in the repository's root documentation.
2. **`cards/`**: Raw HTML mockups demonstrating the deterministic state transitions of the nurse queue cards.
3. **`Recordings/`**: Screen recordings displaying the dual-clock timeline in action, particularly demonstrating the wait-ceiling escalation breaches.
4. **`Pixel_Videos/`**: Production shots used for the final `MediPilot-Pixel-Triage-Reel.md` film submission.
