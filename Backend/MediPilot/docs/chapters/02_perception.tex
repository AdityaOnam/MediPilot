\section{Perception Layer (Track A)}

The Perception Layer bridges the gap between raw human input (voice) and the strict structural requirements of the risk engine.

\subsection{Intake \& Automatic Speech Recognition (ASR)}
The intake process begins with a branching gate determining if the patient is assisted or unassisted, and whether they consent to voice recording. If consent is declined, the patient undergoes an observation-only triage path without penalty.

The Automatic Speech Recognition (ASR) system utilizes a Whisper-class model fine-tuned for Indian-accented speech and code-mixed inputs (e.g., Hinglish). If the ASR confidence score drops below a safe threshold, or if an unsupported language is detected, the system immediately flags a \texttt{communication\_barrier} and falls back to manual nurse text entry.

\subsection{Age-Aware Question Tree}
The patient’s age is extracted early to route them into one of three question trees:
\begin{enumerate}
    \item \textbf{Paediatric:} Focuses on carer-reported observations, feeding, and behaviour.
    \item \textbf{Adult/Adolescent:} Focuses on chief complaint, pain severity (0-10), and pregnancy status.
    \item \textbf{Geriatric:} Focuses on baseline functional decline, confusion, and polypharmacy.
\end{enumerate}

\subsection{Grammar-Constrained LLM Structurer}
A Large Language Model is employed to extract observations from the transcript. However, it operates under strict grammar constraints and JSON schema validation.
\begin{itemize}
    \item \textbf{Allowed Fields:} \texttt{chief\_complaint}, \texttt{onset\_minutes}, \texttt{self\_reported\_severity}, \texttt{symptoms}, \texttt{medications}, \texttt{pregnancy\_status}.
    \item \textbf{Prohibited Operations:} The LLM has \textit{no production rule} for generating a diagnosis or acuity band. The grammar rejects any token generation outside the allowed schema.
\end{itemize}

\subsection{Reliability Flags}
Track A assembles observability signals as pure boolean flags (e.g., \texttt{non\_assisted}, \texttt{analgesia\_given}, \texttt{health\_literacy\_low}). It does not discount or weight these signals; it strictly reports them to Track C, which handles asymmetric reliability discounting.
