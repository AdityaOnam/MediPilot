\begin{abstract}
This document serves as the comprehensive technical specification and implementation manual for the MediPilot prototype. It details the architecture of the end-to-end system, covering the Perception Layer (Track A) and the Risk Engine (Track C). MediPilot employs a strict ``Fail-Closed'' philosophy, utilizing deterministic clinical rule-cards, multi-vital distress floors, and conformal prediction guarantees to ensure patient safety before, during, and after machine learning interventions.
\end{abstract}
